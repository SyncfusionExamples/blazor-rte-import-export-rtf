# Blazor RTE — Import & Export (RTF)

A Blazor sample project showing RTF import and export using Syncfusion Rich Text Editor component.

## Overview

This repository contains a minimal Blazor application that demonstrates how to import RTF documents into the Syncfusion Rich Text Editor and how to export editor content back to RTF files. The sample focuses on the essential integration points needed to enable RTF workflows in a Blazor app.

## Features

- Import RTF files into the Rich Text Editor.
- Export editor content as RTF files for download or storage.
- Demonstrates basic Syncfusion Rich Text Editor configuration in Blazor.

## Prerequisites

- Visual Studio 2022 (or later).
- .NET SDK compatible with the solution (use the version targeted by the project).
- A valid Syncfusion Blazor license key for licensed deployments.

## Setup & Running Steps

Installation

```bash
git clone https://github.com/SyncfusionExamples/blazor-rte-import-export-rtf
cd blazor-rte-import-export-rtf
```

Restore NuGet packages

```bash
dotnet restore
```

Run the application

```bash
dotnet run
```

## Usage

- Use the editor UI to import an RTF file and verify content rendering.
- Use the export action to download or save the current editor content as an RTF file.
